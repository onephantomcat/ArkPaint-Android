# ArkPaint Android

这是 ArkPaint 的原生 Android 版本，可直接构建为 APK 并安装到手机。图像处理、截图和自动绘制均在设备本地完成；应用没有声明网络权限。

当前公开测试版本为 `1.1.1-android`（versionCode `9`）：

- [下载 ArkPaint Android v1.1.1](https://github.com/onephantomcat/ArkPaint-Android/releases/tag/android-v1.1.1)
- [查看 v1.1.1 iQOO / OriginOS 修复说明](../docs/releases/android-v1.1.1.md)
- [查看 v1.1.0 版本说明](../docs/releases/android-v1.1.0.md)

## 环境要求

- Android 11 或更高版本
- JDK 17
- Android SDK Platform 35 与 Build Tools 34.0.0/35.0.0
- 横屏运行的画像册创作页面

## 构建 APK

用 Android Studio 打开本目录即可。也可以在仓库根目录运行：

```powershell
.\scripts\build_android.ps1 -AndroidSdk "C:\path\to\Android\Sdk"
```

或手动创建 `android/local.properties`：

```properties
sdk.dir=C:/path/to/Android/Sdk
```

然后执行：

```powershell
cd android
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

生成的 `app/build/outputs/apk/debug/app-debug.apk` 已由 Android debug key 签名，可以直接侧载安装。正式分发前应改用开发者自己的 release keystore。

## 手机上使用

1. 打开 ArkPaint，导入图片；在裁剪器中单指拖动、双指缩放并确认方形区域，然后调整映射参数。照片或插画建议使用默认的“Lanczos 清晰缩放”和 35～55 细节锐化；原生像素画可改用“邻近采样”。
2. 预览会按游戏内四列调色板从左到右、从上到下显示 `01`～`40` 色号；点击“手动修整”可逐格上色、吸色、撤销/重做并恢复自动转换结果。
3. 点击“保存给绘制器”。首次使用时阅读权限说明并打开系统无障碍设置。
4. 启用“ArkPaint 悬浮绘制器”，返回游戏并进入横屏画像册创作页。
5. 把画布缩放到最小、显示 24×24 网格，并把右侧调色板滚到最顶端。
6. 点击悬浮条“校准”，依次点击：
   - 白色方格画布左上边界（不要点外侧装饰角标）
   - 白色方格画布右下边界（不要点外侧装饰角标）
   - 调色板第一行第一列色块中心
   - 调色板第一行第四列色块中心
   - 调色板第六行第一列色块中心
7. 点击“验证”。应用会在手动点位附近自动吸附真实画布边缘；验证通过后点击“绘制”。若调色板已经在顶部，绘制器会复用当前状态，不再执行两次强制滑动。
8. 绘制中悬浮条会显示完成格数、速度和预计剩余时间。“暂停”会保留当前任务、调色板页和进度，点击“继续”后从同一格接着画；暂停期间请勿缩放画布或滚动调色板。“停止”会结束本轮，手机音量减键仍可紧急停止；之后再次绘制会从截图中识别未完成格。
9. 绘制结束后应用会核对全部 576 格。少量不匹配会自动补画，最多两轮；若不匹配数量异常或补画没有改善，会停止并提示重新绘制或校准。

校准会按屏幕比例保存。系统分辨率、显示缩放或导航栏布局明显变化后，需要重新校准。

在 iQOO / OriginOS 上，v1.1.1 会使用触摸事件的原始屏幕坐标，并在第五点完成后按无障碍截图的实际尺寸换算校准值，避免悬浮层因状态栏、导航栏或挖孔安全区尺寸不同而反复提示“屏幕方向或比例已改变”。升级后需要重新校准一次。

## 小米 Pad / HyperOS 2

本版本以小米 Pad 7（HyperOS 2 / Android 15）为优先兼容目标：悬浮绘制器会延迟启动并自动重试；若系统拒绝标准无障碍悬浮层，会改用“显示在其他应用上层”的备用通道。针对 3200×2136 画面，网格验证会搜索抗锯齿线条边缘，并在误点游戏外侧角标时自动校正到白色画布边界。

首次安装或从旧版升级后建议按以下顺序操作：

1. 先在系统无障碍设置中关闭旧版“ArkPaint 悬浮绘制器”。
2. 安装修复版并打开 ArkPaint，点击“厂商系统悬浮窗权限（备用）”，允许显示悬浮窗。
3. 回到 ArkPaint，点击“开启无障碍服务”，重新打开服务开关。
4. 返回应用；状态应显示“绘制器已启用，悬浮条正常”。如果没有出现，点击“显示 / 重试悬浮条”。

如果系统仍显示“此服务出现故障”，请先关闭无障碍开关再重新开启。主界面会保留最近一次悬浮层异常的具体类型，截图该状态即可继续定位。

## 权限与安全边界

无障碍服务用于三件确定的事情：截取当前画面、执行点击、执行调色板滑动。服务不会自动开始；只有用户点击悬浮条“绘制”后才会运行固定的 24×24 图案脚本。截图不会上传。

应用不会点击画像册中的“保存”“完成”或“发布”。部分应用可能通过安全窗口阻止系统截图，此时 Android 会拒绝验证和绘制。使用自动化前请自行确认游戏规则和账号风险。

## 与桌面版的差异

- 安卓版使用一次性的五点设备校准，以适配刘海、导航栏和厂商分辨率差异。
- 安卓版提供分级 Lanczos、盒式平均、邻近和双线性四种重采样方式；默认使用 Lanczos 并在 24×24 映射前进行可调的边缘锐化。
- 安卓版会按当前截图识别调色板页和已完成格，支持原任务暂停/继续、停止后续画、最终逐格核对以及有限次数的自动补画；画布点击始终使用互不重叠的单指手势，避免游戏误判为缩放。
- 方形裁剪支持拖动与双指缩放；与桌面版相比，尚未提供任意长宽比裁剪框。
