# ArkPaint Android 软件使用说明

本文适用于 ArkPaint Android `1.1.1-android`，重点说明小米 Pad 7 / HyperOS 2 与 iQOO / OriginOS 设备上从导入图片到完成绘制的完整流程。

## 1. 使用前准备

- 安装 Android 11 或更高版本的设备；小米 Pad 7 / HyperOS 2 为优先测试环境。
- 在游戏中进入横屏画像册创作页面。
- 确保能看到完整的 24×24 白色网格和右侧四列调色板。
- 自动操作前自行确认游戏规则和账号风险。

应用不会替你点击“保存”“完成并发布”等最终确认按钮。

## 2. 导入和裁剪图片

1. 打开 ArkPaint，点击“导入图片”。
2. 在 Android 系统文件选择器中选择 JPG、PNG、WebP 等常见图片。
3. 默认会打开方形裁剪器：
   - 单指拖动图片，改变取景位置；
   - 双指缩放图片，控制裁剪范围；
   - 点击“重置”恢复初始位置；
   - 点击“使用此区域”生成 24×24 图案。
4. 如果需要再次裁剪，点击主界面的“调整裁剪范围”。

若不想裁剪，可把“构图方式”改成“整图拉伸”。该模式会保留整张图片，但非正方形图片可能发生横向或纵向变形。

## 3. 调整图案清晰度

### 普通照片或插画

- 缩放清晰度：`Lanczos 清晰缩放（推荐）`
- 像素合并：`1×1 原始格`
- 细节锐化：建议 `35～55`
- 色彩距离：先用默认 CIE Lab，再比较 CIEDE2000 或 OKLab

如果轮廓仍显得发糊，可逐步增加锐化；出现明显白边、黑边或噪点时应降低锐化。不要直接把锐化拉到 100。

### 原生像素画

- 缩放清晰度：`邻近采样（像素画）`
- 像素合并：`1×1 原始格`
- 通常关闭 Floyd–Steinberg 抖动
- 锐化可降到较低值

### 色块和渐变

- 大面积纯色图通常关闭抖动，边缘更干净。
- 渐变较多的图片可开启抖动，但 24×24 画面可能出现颗粒感。
- 2×2～4×4 像素合并适合主动简化图案，不适合追求最大清晰度。

亮度、对比度和饱和度的中间值为 `0`；点击“重置调色”可以恢复默认参数。

## 4. 色号标定和手动像素修改

转换完成后，主预览会按游戏内四列调色板的可见顺序标定色号：每行从左到右，再从上到下，编号为 `01`～`40`。预览下方的“官方顺序用色”会列出当前图案使用的色号及像素数量；关闭“在预览格内显示游戏调色板色号”只隐藏格内文字，不会改变图案。

需要逐格修正时：

1. 点击“手动修整”。
2. 在调色板中选择色号；选中的两位色号和十六进制颜色会显示在调色板上方。
3. 点按单个像素格，或按住拖动连续上色。
4. 点击“吸色”，再点画布中的已有像素，可把它设为当前颜色。
5. 使用“撤销”“重做”检查修改；“恢复为自动转换结果”可还原本次进入编辑器时的图案。
6. 点击“应用修改”，修改会同步回主预览、用色统计、本地保存图案和悬浮绘制器。

如果在主界面再次调整锐化、亮度、映射方式等转换参数，应用会重新计算图片，先前的手动修改会由新的自动转换结果替代；建议先确定转换参数，再进行逐格修整。

## 5. 保存给绘制器

预览满意后点击“保存给绘制器”。这一步只把当前 24×24 图案保存在本机并发送给悬浮服务，不会上传，也不会立刻操作游戏。

如果按钮不可用，请先成功导入图片并等待“正在重算 24×24 图案…”结束。

## 6. 小米 / HyperOS 权限设置

首次安装或升级后建议按以下顺序操作：

1. 点击“厂商系统悬浮窗权限（备用）”。
2. 在系统页面允许 ArkPaint“显示在其他应用上层”。
3. 回到 ArkPaint，点击“开启无障碍服务”。
4. 阅读用途说明后进入系统设置，启用“ArkPaint 悬浮绘制器”。
5. 返回 ArkPaint，确认状态显示“绘制器已启用，悬浮条正常”。
6. 如果悬浮条没有出现，点击“显示 / 重试悬浮条”。

HyperOS 如果频繁结束服务，可在系统的应用电量设置中把 ArkPaint 调整为“不限制”，并允许后台运行。不同 HyperOS 版本的菜单名称可能略有不同。

## 7. 准备游戏画面

1. 切换到游戏横屏画像册创作页面。
2. 把白色画布缩放到最小，确保完整显示 24×24 网格。
3. 把右侧调色板滚到最顶部。
4. 不要让通知栏、键盘、弹窗或其他悬浮内容遮挡画布与调色板。
5. 可拖动 ArkPaint 悬浮条顶部区域，把它移到不遮挡画布的位置。

## 8. 首次五点校准

点击悬浮条“校准”，按提示依次点击：

1. 白色方格画布左上边界，不要点外侧装饰角标；
2. 白色方格画布右下边界，不要点外侧装饰角标；
3. 调色板第一行第一列色块中心；
4. 调色板第一行第四列色块中心；
5. 调色板第六行第一列色块中心。

应用会按屏幕比例保存校准。切换分辨率、显示缩放、导航栏布局或屏幕方向后，应重新校准。

iQOO / OriginOS 设备在点击第五个点后会短暂显示“正在匹配当前设备的截图比例…”。请等待状态变为“校准完成”后再点“验证”；v1.1.1 会自动换算悬浮层、状态栏、导航栏和系统截图之间的坐标差异。

## 9. 验证和开始绘制

1. 校准完成后点击“验证”。
2. 应用会检查横屏状态、24×24 网格、画布边界和调色板位置，并自动吸附真实边缘。
3. 状态显示“画布与调色板已验证，可直接绘制”后，点击“绘制”。
4. 绘制器会识别当前调色板页和已完成格，再按颜色顺序执行单指点击。

点击间隔越短速度越快，但设备掉帧或游戏没有及时响应时可能漏格。出现漏画时应适当增加点击间隔。

## 10. 暂停、继续和停止

- **暂停：** 保留当前任务、格子进度和调色板页。等状态明确显示“已暂停”后再进行其他操作。
- **继续：** 从暂停位置的同一任务继续，不会从头开始。
- **停止：** 结束本轮绘制；下一次点击“绘制”时会通过截图识别未完成格并续画。
- **紧急停止：** 绘制期间按设备“音量减”键。

暂停期间不要缩放或移动画布，也不要滚动调色板，否则继续后的坐标和页面状态可能不再对应。

## 11. 完成核对

绘制结束后，应用会核对全部 576 个格子：

- 少量不匹配会自动补画，最多两轮；
- 如果不匹配数量异常，或补画没有改善，绘制器会停止并提示重新校准或重新绘制；
- 状态显示“核对 576/576”后，由用户自行检查并点击游戏中的保存或发布按钮。

## 12. 常见故障排查

### 导入图片后没有出现裁剪器

1. 确认选择的是系统可以读取的有效图片，而不是云端尚未下载完成的占位文件。
2. 回到主界面点击“调整裁剪范围”。
3. 如果提示“无法读取这张图片”，先在系统相册中把图片另存为 PNG 或 JPG 后重试。
4. 强制关闭旧版后重新打开当前版本，避免升级后残留的旧页面状态。

### 悬浮条不出现或系统提示服务故障

1. 在系统无障碍设置中关闭“ArkPaint 悬浮绘制器”。
2. 回到 ArkPaint，确认“厂商系统悬浮窗权限（备用）”已允许。
3. 再次进入无障碍设置并重新开启服务。
4. 返回应用，点击“显示 / 重试悬浮条”。
5. 如仍失败，完全结束 ArkPaint 后重新打开；查看主界面的具体故障状态。

### 验证提示“画布网格不足”

- 确认处于横屏画像册创作页，而不是预览或发布页面。
- 把画布缩放到最小并完整显示 24×24 网格。
- 关闭遮挡画布的弹窗和悬浮内容。
- 把调色板滚到顶部并重新做五点校准。
- 点击边界时应点白色方格的真实边缘，不要点四角外侧装饰标记。

### iQOO / OriginOS 反复提示“屏幕方向或比例已改变”

1. 确认已升级到 v1.1.1 或更高版本；v1.1.0 仍可能把悬浮层高度误当成系统截图高度。
2. 关闭游戏小窗、分屏和悬浮键盘，保持画像册为完整横屏。
3. 重新执行五点校准，并等待“正在匹配当前设备的截图比例…”结束。
4. 校准完成后先点“验证”，不要在校准和验证之间切换导航方式、显示分辨率或显示大小。

### 暂停后继续位置不正确

- 必须等悬浮条显示“已暂停”后再触碰其他界面。
- 暂停期间不要缩放画布、改变横竖屏或滚动调色板。
- 如果画面已经变化，先停止，再重新验证后续画。

### 绘制结果模糊

- 普通图片使用 Lanczos、1×1 原始格和 35～55 锐化。
- 像素画改用邻近采样并关闭抖动。
- 重新裁剪，让主体尽量占满方形区域。
- 24×24 本身细节有限；优先选择轮廓清晰、主体居中、背景简单的原图。

### 漏画或颜色位置错误

- 适当增加点击间隔。
- 确保调色板起始时位于顶部。
- 重新验证；如果屏幕布局变化则重新校准。
- 使用“停止”结束异常任务，再重新绘制以识别未完成格。

## 13. 隐私和安全边界

- 应用未声明网络权限，图片和截图不会上传。
- 无障碍操作只在用户点击“绘制”后启动。
- 应用不会读取账号密码，也不会自动确认保存或发布。
- 可随时用悬浮条“停止”或设备“音量减”键中止自动绘制。
